Sistem Informasi Web & CMS Dinas Kebudayaan Kota Ternate (Kontrak Rp 25 Juta)

Milestone besar di Semester 7: Membangun portal resmi dan CMS admin mandiri untuk Dinas Kebudayaan Kota Ternate selama 5 bulan pengerjaan dengan koding manual murni sebelum era otomatisasi AI.

Teknologi & Instrumen yang Digunakan:
Native PHP MySQL Relational DB Custom CMS Admin HTML5 & CSS3 JavaScript E-Government Portal

Tantangan & Masalah Klien

Dinas Kebudayaan Kota Ternate membutuhkan sarana informasi digital resmi untuk mempublikasikan program kebudayaan daerah (seperti Muhibah Budaya Jalur Rempah dan Festival Ela-Ela), direktori pejabat/satuan kerja, serta portal unduhan dokumen resmi (Renstra & Perencanaan Anggaran). Dibangun pada era awal transisi teknologi, proyek ini menuntut pengembangan fullstack mandiri dari struktur database MySQL hingga panel admin tanpa bantuan framework berat atau generator kode otomatis.

Solusi Lapangan

Merancang dan mengoding arsitektur web secara mandiri selama 5 bulan penuh: pembuatan skema basis data MySQL terelasi (tabel berita, agenda, pejabat, dokumen), antarmuka publik yang informatif, modul upload dokumen PDF, galeri agenda budaya, serta membangun "Disbud Admin" (CMS khusus staf dinas untuk mengelola konten dan data pejabat secara dinamis). Proyek bernilai kontrak Rp 25.000.000 ini sukses diserahterimakan secara resmi kepada dinas (dokumentasi portofolio ini mencerminkan versi orisinal sistem saat serah terima selesai).
