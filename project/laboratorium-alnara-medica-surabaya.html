Portal Terintegrasi Laboratorium Alnara Medica Surabaya & Mini-LIS

Portal laboratorium klinis terintegrasi mencakup 11 layanan pemeriksaan medis, denah 2 lantai seluas 1.600 m², katalog 16 instrumen medis senilai Rp 13,08 M, Mini-LIS online, serta modul evaluasi akademik.

Teknologi & Instrumen yang Digunakan:
Next.js / React Tailwind CSS Mini-LIS System Clinical Portal Vercel Edge GitHub
Live Demo GitHub Repo

Tantangan & Masalah Klien

Laboratorium klinis modern dan program studi Teknologi Laboratorium Medis (TLM) membutuhkan portal digital profesional yang menyatukan informasi layanan pasien, spesifikasi peralatan diagnostik berstandar klinis, serta simulasi Laboratory Information System (Mini-LIS) dengan isolasi layout admin yang rapi.

Solusi Lapangan

Merancang aplikasi web modern berarsitektur modular dengan isolasi layout khusus untuk panel Admin LIS, katalog interaktif 11 layanan laboratorium & 16 instrumen medis, visualisasi denah fasilitas 2 lantai, serta deployment produksi cepat di Vercel Edge Network.
