## 🚀 Menjalankan Secara Lokal

Untuk menguji atau memodifikasi website ini di lingkungan lokal:

1. **Clone Repositori:**
   ```bash
   git clone https://github.com/owensavala/muhsattarbarakati-portfolio.git
   cd muhsattarbarakati-portfolio
   ```

2. **Jalankan Local Web Server:**
   Anda dapat menggunakan ekstensi *Live Server* di VS Code atau menjalankan server lokal bawaan Python:
   ```bash
   python -m http.server 3000
   ```
   Buka di browser: `http://localhost:3000`
